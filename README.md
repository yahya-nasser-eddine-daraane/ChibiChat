# ChibiChat

A Java-based chat application consisting of a client and a server module.

## Project Structure

- `client/`: The JavaFX client application.
- `server/`: The backend server application.

## Getting Started

### Prerequisites
- Java JDK 17 or higher
- Maven
- SQL Server (for the server database)

### Running the Client
Navigate to the `client/` directory and run:
```bash
./run_final.bat
```

### Running the Server
Navigate to the `server/` directory and run:
```bash
./run_server.bat
```
